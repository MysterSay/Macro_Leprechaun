# Теми плаваючої панелі · 0.17

Панель використовує перенесений вебрендерер Kando: Menu, MenuTheme, CenterText, сектори, роздільники, pointer/keyboard/gesture/gamepad input, звуки. Основний процес і виконання макросів залишаються Go. У Windows меню відкриває окремий процес WebView2 із прозорим контролером; він завершується після закриття меню. Прев’ю використовує той самий JS/CSS у вкладеному вікні, а вибір пункту в редакторі лише вибирає нашу кнопку.

## Розміщення

`data/effects/floating/<id>/theme.json5` (або `theme.json`) та `theme.css`.

У комплекті оригінальні теми Default, Clean Circle, Neon Lights, Purity, Rainbow Labels із пресетами й SVG-ресурсами з Kando. `sounds-simple-clicks` — звукова тема; `_engine` — базовий CSS рендерера. Папки, які починаються з `_`, не з’являються у списку тем. ID: латинські літери, цифри, `_`, `-`, до 80 символів.

Найпростіше скопіювати папку наявної теми під новою назвою та змінити `name`, `author`, кольори й CSS. Додайте власну ліцензію, зберігши інформацію про запозичені файли. Перекомпіляція Go, Java або JS для нової теми не потрібна.

Список перечитується при відкритті «Плаваюча панель → Редагувати». Для оновлення вже відкритого меню закрийте й відкрийте його знову. Штатні файли, яких бракує, копіюються з EXE під час запуску; наявні файли не перезаписуються.

## Опис теми

```json5
{
  name: 'Моя тема',
  author: 'Ваше ім’я',
  license: 'CC0-1.0',
  themeVersion: '1.0',
  engineVersion: 1,
  maxMenuRadius: 160,
  centerTextWrapWidth: 95,
  drawChildrenBelow: true,
  drawCenterText: true,
  drawSelectionWedges: true,
  drawWedgeSeparators: false,
  colors: {
    'background-color': '#19201c',
    'text-color': '#edf3ee',
    'hover-color': '#64d98a'
  },
  layers: [{ class: 'icon-layer', content: 'icon' }]
}
```

Кожний пункт є `.menu-node`. Шари створюються у зворотному порядку масиву, як у Kando. `content`: `icon`, `name`, `quick-select-key`; без `content` шар порожній і може малювати довільний декоративний ефект. `class` — один CSS-ідентифікатор. Можна використовувати кілька шарів, зображення, SVG-маски, шрифти, CSS-анімації, тіні та прозорість. Ресурси в `assets/` адресуйте з CSS відносно файла: `url(assets/ring.svg)`.

`colors` автоматично стають полями налаштувань і CSS-властивостями `--<назва>`. Підтримуються CSS-кольори, зокрема `rgb(...)`, `rgba(...)`, `hsl(...)`, прозорі кольори. Поле тексту зберігає альфа-канал; кольорова кнопка зручна для вибору непрозорого RGB.

Стан пункту передається класами оригінального рендерера: `active`, `parent`, `child`, `grandchild`, `hovered`, `clicked`, `dragged`, напрямками `left/right/top/bottom`, `level-N`, `type-button/root/submenu`. `data-name` містить підпис пункту. Наші кнопки стають пунктами `button`, а переходи «Папок Леприкона» виконуються через наші макроси й сесію навігації.

CSS-властивості Kando включають `--dir-x`, `--dir-y`, `--angle`, `--sibling-count`, `--start-angle`, `--end-angle`, `--parent-angle`, `--angle-diff`, `--pointer-angle`, `--hover-angle`, `--hovered-child-angle`, `--parent-start-angle`, `--parent-end-angle`, `--quick-select-key`. Точні приклади всіх ефектів є в оригінальних CSS тем; `--child-distance`, `--center-size` тощо — змінні, які самі теми оголошують для своїх розмірів.

## Пресети

`presets/Назва.json`:

```json
{"colors":{"background-color":"#161c18","text-color":"#ffffff"}}
```

Після вибору пресета можна змінювати окремі кольори. Вибір теми, кольори та поведінка зберігаються окремо для кожної панелі у її `floatingStyle`; файли самої теми при цьому не змінюються.

## Поведінка

У вікні редагування є масштаб, сектори вибору, швидкі клавіші, тривалість появи/зникнення, анімації, реакція на курсор; центральна зона, максимальний радіус вибору, поріг перетягування, marking/turbo/hover mode, фокус, Windows Ink, фіксоване положення, параметри розпізнавання жестів і кнопки геймпада. Одиниці підписані біля полів. Turbo mode вимикається, якщо ввімкнено збереження фокусу іншої програми — так працює оригінальний рендерер.

У прев’ю вибір макросів, warp курсора, turbo/marking і геймпад вимкнені, щоб редагування не запускало дії та не рухало системний курсор. Нативне меню отримує збережені налаштування. Коліщатко не змінює порядок кнопок; використовуйте контекстне меню «Перемістити раніше/далі».

## Звуки

Звукова тема має `engineVersion: 2` і `sounds`, як у Kando. Події: `openMenu`, `closeMenu`, `openSubmenu`, `closeSubmenu`, `hoverParent`, `hoverButton`, `hoverSubmenu`, `selectButton`. Для кожної — `file`, необов’язкові `volume`, `minPitch`, `maxPitch`. Файли WAV/MP3/OGG зберігаються поруч. У комплекті збережено умови Pixabay та авторів кожного звука. Типово звук вимкнений; увімкніть тему в розділі «Звуки». Прев’ю не відтворює звуки.

## Вихідний код і збірка рендерера

Оригінал зафіксовано на коміті `d860e24da203f8969872f62846fad5a6a859e522` репозиторію https://github.com/kando-menu/kando. Незмінені вибрані файли збережені в `third_party/kando`. Робоча адаптація — `desktop/floating-src`; адаптери підміняють Electron IPC на наші повідомлення та Go API, завантаження `file://` на локальні HTTP-ресурси, а реєстр значків — на наші значки.

Для зміни коду рендерера: `cd desktop/floating-src`, `npm ci`, `npm run build`. Уже зібрані JS і базовий CSS входять до архіву. Після зміни коду чи вбудованих початкових тем перебудуйте EXE. Для зміни CSS/JSON у користувацькій `data` нічого збирати не потрібно.

Теми не виконують власний JavaScript. Сторонні скрипти, зовнішні мережеві ресурси й вихід за межі папки теми заблоковані. Шрифти та зображення потрібно постачати локально.
