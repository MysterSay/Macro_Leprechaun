# MacroLeprechaun 0.15.0

- Редактор Windows тепер використовує **WebView2**, окремий процес програми та власний профіль `data/setting/webview2`. Особистий профіль Edge, його розширення та синхронізація не завантажуються. Закриття редактора завершує його процес; макроси, телефон і нативні віджети продовжують працювати. Завершення основної програми закриває також редактор. Повторне відкриття активує наявне вікно.
- Типово повні тіла макросів **не зберігаються в RAM**. У пам’яті лише каталог: ID, назва, input і залежності. JSON читається для запуску або редагування конкретного макроса; після завершення посилання на його тіло звільняється. Запити статусу та телефону не копіюють усі тексти пазлів. Зміни на диску читаються наступним запуском. Налаштування «Тримати всі макроси в оперативній пам’яті» повертає постійний кеш; типово вимкнене.
- Зовнішні змінні, на які немає посилань у ввімкнених панелях/їхніх макросах та підписах, не опитуються. Зберігається останнє значення. Відкритий розділ змінних тимчасово відновлює опитування доступних змінних; закриття/приховування зупиняє цю потребу. Перед запуском макроса потрібні показники оновлюються (кеш провайдера — 2 с; мережі — 10 с). «Оновлювати також невикористані змінні» типово вимкнене.
- «Статистика ПК» 1.2.0 отримує список потрібних показників і не виконує зайвих запитів CPU/RAM/GPU. Вимкнені у налаштуваннях доповнення показники не з’являються у списку змінних.

**Оновлення:** закрийте програму, замініть `build/MacroLeprechaun.exe` та папку `data/plagin/pcstats` відповідною папкою з архіву. Решту власної `data` збережіть. APK сумісний. Для редактора потрібен **Microsoft Edge WebView2 Evergreen Runtime**; якщо його немає, програма покаже повідомлення. WebView2 також використовує Chromium, тому нульового або фіксованого споживання RAM не обіцяємо. Економний режим застосовується після збереження налаштувань; Windows може повертати звільнену пам’ять поступово.

Додано тести читання файлу тільки на вимогу, захисту каталогу та призупинення провайдерів. Нативне вікно WebView2 і його фактичне споживання RAM потребують перевірки на Windows.

## Нове у 0.9.0: панелі, змінні й дії

Ліворуч від сітки — дерево панелей, праворуч стовпчик «Панелі / Макроси / Пристрої». У «Редагувати панель» є батьківська панель. Кореневі панелі мають порожнє parent; цикли заборонені. Для дочірніх нативних панелей не створюється окремий крайовий віджет або глобальна клавіша: вони відкриваються пазлами у наявній панелі.

### Панелі Леприкона

«Змінити папку» відкриває список панелей поточного режиму і рядок назви/пошуку. Зберігається ID вибраної панелі. Вимкнена/видалена панель дає помилку в журналі. «Перейти в батьківську папку» без налаштувань повертає до попередньої панелі; якщо історія порожня — до parent або головної. «Перейти в кореневу папку» переходить на першу увімкнену кореневу панель цього режиму й очищає історію.

Телефон показує лише активну панель; навігаційних стрілок немає. Історія окрема для кожного підключення. Віджети та плаваючі панелі мають окремий стан для кожної початкової панелі. Їхнє розташування й гаряча клавіша залишаються налаштуваннями початкового віджета, змінюються назва й кнопки. Плаваюче меню після переходу відкриває наступну панель у тому самому місці. Стан навігації скидається при перезапуску сервера.

### Дії

- **Затримка:** п’ять частин ДД:ГГ:ХХ:СС:ММ, остання — мілісекунди 0–999. Години 0–23, хвилини/секунди 0–59, дні 0–365. Новий пазл бере останній введений час із локального сховища редактора. Очікування не утримує блокування текстового вводу.
- **Умова:** ширина двох звичайних пазлів, одна вихідна гілка. Кожне порівняння — змінна = буквальний текст або інша змінна. Порівняння точне й регістрозалежне: «1» не дорівнює «1.0». Хибна умова завершує поточну гілку. `if`: перше порівняння істинне; `else`: перше хибне; `and`: обидва істинні; `not`: обидва хибні (NOR, за замовленою логікою); `or`: принаймні одне істинне. Відсутня змінна — помилка, а не приховане false.
- **Чекати:** ті самі порівняння. Спочатку показано порівняння двох змінних; кнопкою можна замінити праву частину статичним значенням. Повторна перевірка кожні 100 мс до істини; немає автоматичного 60-секундного обмеження. Інші макроси й редактор можуть змінити змінні. Поки умова хибна, пазли далі не виконуються. Перезапуск/закриття програми припиняє очікування.
- **Запустити макрос:** список актуальних макросів. Запускає незалежну паралельну гілку й одразу продовжує поточну. Для input button — click, toggle — true, slider — поточне значення його змінної (воно має вкладатися в max). Один ID одночасно виконується один раз, загалом до 8 макросів; циклічні виклики і вкладеність понад 16 відхиляються.
- **Записати змінну:** наявна змінна, джерело — виділення, Unicode-буфер, текстовий файл або статичний текст. Виділення використовує Windows Edit/UI Automation із попередніми обмеженнями. Документи: UTF-8 (із BOM або без) чи UTF-16 LE/BE з BOM; до 1 MiB. Порожнє значення допустиме.
- **Прочитати змінну:** значення вставляється в активне поле без буфера, записується у Unicode-буфер або перезаписує вибраний документ у UTF-8. Самостійного створення відсутніх папок немає.

Змінні спільні для всіх макросів у поточному процесі; зміни від пазлів відразу доступні умовам/очікуванню. Автоматичного окремого запису кожної runtime-зміни у SQLite немає: персистентні налаштування, як і раніше, записуються кнопкою «Зберегти зміни» з редактора. Редактор підтягує runtime-значення через status кожні 3 секунди, якщо це значення не було змінене локально вручну; локальні правки мають пріоритет. Після синхронізації кнопка Save записує актуальні значення.

Текстові та Win-пазли працюють як раніше; пазли доповнень все ще потребують окремого підключення. Це відновлення стосується саме відсутнього файла (`IsNotExist`). Помилки доступу, пошкоджений JSON або база налаштувань не маскуються під порожні дані. Перевірено запуск після реального видалення JSON, обидві кнопки у браузері, збереження/перезапуск та Go -race. APK сумісний.

Старі пазлові макроси без прив’язок до кнопок/вимкнення/пазла запуску макроса прибираються з редактора при завантаженні; натисніть **Зберегти зміни**, щоб записати очищений список на диск. Після успішної транзакції сховище прибирає власні застарілі JSON-файли. Макроси не об’єднуються лише через однакову назву. Дублювання кнопки створює її незалежний макрос. Зміна input-типу, якщо інший контрол користується тим самим макросом з іншим типом, також створює окремий актуальний макрос.

Усі вісім Win-пазлів мають кнопку налаштування з окремим діалогом. Зміни діалогу записуються у чернетку пазла після «Зберегти», у макрос після «Застосувати», на диск після «Зберегти зміни».

- **Команда:** термінали виявляються при відкритті діалогу: Windows PowerShell, PowerShell 7, CMD, Python, py та встановлені WSL-дистрибутиви. Є команда, робоча папка й необов’язковий файл stdout+stderr (перезапис UTF-8). Команда виконується приховано до 60 секунд; це не інтерактивна сесія терміналу. PowerShell/Python приймають код відповідного інтерпретатора, CMD/WSL — shell-команду. WSL використовує sh. Незвичайні імена дистрибутивів з лапками відхиляються. CLI-утиліти зі своєю нестандартною кодувальною сторінкою можуть потребувати налаштування UTF-8 у самій команді.
- **Файл:** вибір файлу й програми або типова асоціація Windows. Можна вибрати інший EXE вручну. Пакетні програми у списку «відкрити за допомогою» не показуються, бо не всі приймають довільний шлях файлу як аргумент.
- **Папка:** вибір папки й відкриття у Провіднику.
- **Програма:** EXE вручну або список App Paths, exe-ярликів меню «Пуск» і пакетних програм Get-StartApps; окремий рядок аргументів. Список не охоплює всі переносні EXE на дисках. Для shell:AppsFolder аргументи не підтримуються. Аргументи вводяться зі звичайним Windows-екрануванням лапками.
- **Звук:** активні пристрої render/capture через Windows Core Audio. Для кожного — mute, +/- процентні пункти або значення 0–100 зі змінної. Пристрій «за замовчуванням» визначається на момент виконання, роль Multimedia. Пауза/play, stop і перемикання треків — глобальні медіаклавіші активному плеєру; вони не належать до конкретного аудіопристрою. Mute мікрофона вимикає звук, не від’єднує пристрій. Роботи з окремими аудіосесіями програм у цій версії немає.
- **Браузер:** http/https URL у типовому браузері; back/forward/home/refresh — клавіші активному вікну браузера.
- **Клавіші:** 5 стовпчиків, ліві/праві Win/Ctrl/Shift/Alt, категорії стандартних, навігаційних, F1–F24, NumPad, медіа-, браузерних клавіш і 5 кнопок миші. Власні теги X-Mouse Button Control не виконуються: у них є окремі залежності від X-Mouse, які тут не реалізовані. Це меню у подібній структурі, а не імпорт X-Mouse.
- **Клікер:** живі екранні координати, ручне введення, фіксація глобальним Space через опитування Windows, включно з від’ємними координатами інших моніторів; переміщення та вибрані кнопки миші у порядку ПКМ → СКМ → ЛКМ → 4 → 5. Без обраних кнопок — лише переміщення. Дуже короткий Space між опитуваннями може бути пропущений; утримайте його на мить.

Нативні діалоги, термінали та Core Audio викликаються прихованим системним Windows PowerShell. Незмінний службовий скрипт тимчасово записується у temp і прибирається після завершення. Його параметри передаються JSON через stdin; для службового процесу використовується ExecutionPolicy Bypass, який не змінює системну політику. Корпоративна Group Policy може блокувати виконання. Native inventory/pickers/cursor API доступні лише локальному авторизованому редактору; телефон передає тільки тригери збережених макросів.

Перевірено Go -race, формат INPUT для клавіатури/миші, доступ до API, збереження payload, браузерні діалоги з підставленими Windows-відповідями, повторне редагування без приросту макросів і очищення старих копій. Нативні Win32/Core Audio/PowerShell-дії на фізичному Windows тут не виконувались. APK не змінено.

## Нове у 0.6.0

Редактор завжди містить один незнімний блок **input**. Його виходи залежать від типу елемента:

- Кнопка: click і одна послідовність.
- Перемикач: окремі виходи true та false. Натисніть потрібний вихід, а потім пазл у палітрі — він додасться до цієї гілки.
- Повзунок: значення від 0 до заданого максимуму; у блоці є повзунок-прев’ю, числове поле, максимум і вибір змінної. На телефоні — range та числове введення з відсотками. Після зміни значення записується у вибрану змінну перед активацією гілки.

Під час перетягування вихід поблизу підсвічується магнітом. Відпустіть блок біля виходу, щоб приєднати його. З’єднання записуються явно за ID, а не виводяться з координат. Перенесення блока переносить його хвіст. Перенесення вбік від’єднує від попередника; приєднання до зайнятого виходу вставляє хвіст перед попередньою послідовністю. Сірі блоки з позначкою «не приєднано» не відвідуються. Цикли, неіснуючі посилання, кілька input і кілька батьків одного блока відхиляються при збереженні.

При активації input сервер проходить тільки відповідну гілку у порядку з’єднань. **Нетекстові дії пазлів залишаються заготовками:** сервер записує їх у журнал без виконання команд Windows чи інших нових дій. Реально працюють input, маршрутизація true/false та запис значення повзунка. Попередні steps-макроси виконуються як раніше.

Перемикач на телефоні — ціла кнопка, що залишається візуально натиснутою до вимкнення. Стан синхронізується з ПК й іншими телефонами та відновлюється після перезавантаження сторінки; перезапуск сервера скидає його. Текстовий тип елемента прибрано з інтерфейсу. У звичайної кнопки є параметр **Активація: тривалість натиснення, с**, типово 0,22 с, діапазон 0–60 с. Це тривалість візуального ефекту після відпускання, не затримка виконання.

APK 0.5.0 сумісний. Достатньо оновити EXE, зберігши data, та перепідключити/перезавантажити панель телефона.

## Запуск і підключення

1. Розпакуйте архів у постійну папку. Запустіть build/MacroLeprechaun.exe.
2. Налаштування відкриються у Microsoft Edge у режимі застосунку, або у стандартному браузері, якщо Edge відсутній. Сервер, дані, макроси та оверлеї працюють у Go.
3. Встановіть build/MacroLeprechaun.apk на Android 8+. Телефон і ПК — в одній локальній мережі.
4. На ПК відкрийте **Налаштування → Підключити телефон → Створити код підключення**.
5. У телефоні знайдіть ПК або введіть його IP-адресу, підключіться й введіть шестизначний код. Код одноразовий, діє 5 хвилин. Після п’яти невдалих спроб з однієї IP потрібен новий код.

Збережені пристрої можна відкликати в Налаштуваннях. Якщо мережа заблокована Windows, дозвольте програмі приватну мережу або запустіть build/Allow-LocalNetwork.ps1 від адміністратора. Порти: TCP 47640, UDP 47641 і mDNS 5353. Пряме IP-підключення не залежить від mDNS; ім’я macroleprechaun.local:47640 спільне для цієї версії. Зміна порту потребує перезапуску сервера й відповідного правила брандмауера.

Закриття браузерного вікна залишає сервер у треї. Лівий клік на значок — налаштування; правий — меню Exit. Друга копія на тому самому порту не запускається.

## Smart-панель: клітинки та вигляд кнопок

Сітка має окремі фіксовані клітинки. Перетягніть кнопку в будь-яку порожню клітинку; інші кнопки залишаються на місці. Якщо ціль зайнята, кнопки міняються місцями. Порожні клітинки лишаються порожніми й на телефоні. Кількість рядків і стовпців налаштовується в «Редагувати». Фон вибирається кнопкою, яка відкриває галерею мініатюр із data/image; є варіант «Без фону». Ліміти: до 8 стовпців, 30 рядків, 48 кнопок та 240 позицій у панелі.

Один клік на кнопку відкриває налаштування під сіткою:

- текст і тип: кнопка / перемикач / повзунок;
- символ, значок із онлайн-каталогу або файл SVG/PNG/JPG/GIF/WebP;
- анімація іконки: без анімації, пульсація, обертання, плавання;
- ефект: без ефекту, світіння, тінь, скло;
- натискання: стиснення, без ефекту, спалах, хвиля;
- кольори тексту, контуру, фону та символу;
- фонове зображення кнопки з data/image. Змінних у кнопках немає — вони належать пазлам.

Живе прев’ю поруч. Відображення на телефоні оновлюється після **Зберегти зміни**. Усі клітинки поточної панелі завжди розміщуються на одному екрані. Іконки, текст, відступи й поля зменшуються разом зі збільшенням сітки, у портретній та альбомній орієнтації. Сторінок, стрілок навігації, прокручування, логотипу й заголовка немає. Автономної навігації між панелями немає: майбутні переходи до папок виконуватимуться кнопками й пазлами; їх виконання досі не підключено. Кнопка «Назад» Android повертає до підключення.

## Редактор пазлів

- у центрі — поле з сіткою, назва й значок макросу;
- справа — збережені макроси-шаблони. Натискання копіює їхні пазли на поле, не змінюючи оригінал.

Перетягуйте пазли з палітри або натискайте на них, щоб додати до кінця. Перетягуйте готовий пазл за заголовок. Поле прив’язує координати до сітки; біля нижнього стику іншого пазла блок прилипає до нього. «×» видаляє блок. Значення параметрів зберігаються як текст; текстові дії мають окремі редактори. До 100 пазлів у макросі. Застосувати зберігає чернетку у редакторі панелі, а **Зберегти зміни** записує її на диск.

Категорії:

- **Текст:** Вставити текст, Вставити в буфер обміну, Трансформувати, Виділити, Знайти текст.
- **Win:** Запустити команду, Запустити файл, Відкрити папку, Запустити програму, Звук, Управління браузером, Гарячі клавіші, Клікер.
- **Папки Леприкона:** Змінити папку, Перейти в батьківську папку, Перейти в корінну папку.
- **Дії:** Затримка, Умова, Запустити макрос, Записати змінну, Прочитати змінну.
- **Плагіни:** власні категорії з маніфестів увімкнених доповнень.

**Нетекстові пазли поки заготовки**, включно із затримкою, умовою та плагінами. Текстові дії описано вище. Редагування графа саме по собі нічого не запускає; потрібна активація кнопки. Папки Леприкона означають майбутні папки панелей, не файлову систему Windows.

Попередні макроси з steps працюють як раніше, доки їх не переведено в пазли через новий редактор. При редагуванні створюється окрема puzzle-копія, попередній шаблон не змінюється. Макрос graphVersion=1 використовує явні з’єднання від input і не запускає старі steps. Чернетки puzzles попередніх версій без input залишаються неактивними, доки їх не буде відкрито й збережено у новому редакторі.

## Файли

Корінь даних — data поряд із EXE (у пакеті це build/data). Можна явно задати `-data "F:\Data\MacroLeprechaun"`.

| Папка | Вміст |
|---|---|
| data/macros | JSON кожного макросу, включно з пазлами та координатами |
| data/setting | settings.sqlite: налаштування програми, панелей і кнопок; schema.sql: структура SQL; devices.json: токени спарених телефонів |
| data/icon | база локальних іконок; PNG, JPG/JPEG, GIF, WebP |
| data/image | зображення для фону панелей у тих самих форматах |
| data/plagin | папки доповнень із manifest.json |
| data/locales | зовнішні JSON-переклади uk.json, en.json та власні мови |

Щоб додати іконки або фони, покладіть файли до відповідної папки й оновіть вікно налаштувань. GIF-іконки зберігають власну анімацію. Кольоризація змінює символи; колір растрових зображень не перефарбовується. SVG-значки підтримуються: вони відображаються як локальні зображення, а не вставляються у HTML.

Макроси мають імена id.hash.json. Незмінні JSON-файли спочатку записуються на диск, а SQLite-транзакція переключає індекс на них разом із налаштуваннями. Це захищає попередній профіль при невдалому записі. Таблиці: settings, panels, buttons, macro_files. Для резервної копії копіюйте всю data при закритій програмі або використовуйте експорт профілю. Експорт не включає файли іконок, фонів, доповнень чи токени телефонів; переносіть їх окремо.

## Значки та ефекти 0.5.0

У властивостях кнопки натисніть **Вибрати значок**. Джерела:

- Iconify — пошук за запитом;
- Simple Icons і Devicon — їхні колекції через Iconify;
- SVGL — пошук назв у власному API;
- VectorLogoZone — точний ідентифікатор бренду, наприклад github; для інших варіантів можна вставити прямий SVG URL;
- Мої файли — значки з data/icon та імпорт SVG/PNG/JPG/GIF/WebP.

«Відкрити джерело» відкриває відповідний сайт. Можна вставити пряме HTTPS-посилання на SVG/зображення з підтримуваного сайту або його офіційного CDN/GitHub. Посилання на HTML-сторінку не є файлом значка. Значок завантажується на ПК у data/icon, а телефон отримує локальний файл; постійне інтернет-з’єднання телефону не потрібне. Поряд із завантаженим значком зберігається .source.json з URL джерела. Онлайн-пошук потребує інтернету на ПК. Великі файли краще скопіювати безпосередньо в папку; імпорт HTTP обмежено 2 MiB тіла запиту.

Окремий вибір **Фон кнопки** використовує data/image; його не слід плутати зі значком. Колір символу застосовується до текстових значків, растрові та багатокольорові SVG зберігають оригінальні кольори.

Анімації використовують сумісні transform-keyframes; світіння/скло мають RGBA-стилі без залежності від color-mix. Ефект натиснення запускається Pointer Events і утримується короткий час після відпускання пальця. Кеш HTML/CSS/JS вимкнений, URL ресурсів має номер версії. Старе поле variable збережено у форматі JSON для сумісності імпорту, але в налаштуваннях його немає і клієнтські значення через нього не записуються.

## Віджет та плаваюче меню

Віджети лишаються вертикальними списками: смуга 2–12 px на вибраному краї/моніторі, наведення відкриває острівець, відведення ховає. Правий клік відкриває налаштування.

Плаваюче меню: прозорий фон, круглі кнопки та вибір напрямком від центру, за геометрією базової теми Kando. Ctrl+Alt+Space типово. Вибір — лівий клік у напрямку дії або утримання основної клавіші комбінації та її відпускання після переміщення курсора. Центр неактивний. Повторна комбінація/правий клік/Esc закривають меню. Конфлікти гарячих клавіш потрапляють у журнал. Повні анімації, вкладені меню та жестовий рушій Kando поки не перенесені.

## Доповнення, теми, розробка

Контракт API та puzzleCategories: docs/PLUGIN_API.md. Приклад виконуваного модуля: modules/example; встановлювати до data/plagin/example. Увімкніть його в Доповненнях і збережіть. Доповнення працюють із правами користувача, тому встановлюйте власні або перевірені. Пазли з їхніх категорій у 0.4.0 лише візуальні.

Темна тема та зелений акцент типово; є світла тема і власний колір. Для нової мови скопіюйте словник у data/locales й введіть код файла у Налаштуваннях. Раніше створені назви й параметри користувача автоматично не перекладаються. Застарілі словники доповнюються новими вбудованими ключами.

Збирання Windows: Go 1.22+, `powershell -ExecutionPolicy Bypass -File build.ps1`. SQLite — modernc.org/sqlite, без DLL і CGO. Ресурс іконки EXE вже включено. Android: JDK 17, Android SDK 35, Gradle 8.9 або android/build-manual.sh. Development APK 0.5.0 у пакеті підписаний тим самим ключем, що й 0.3.0.

Автоматично перевіряються збереження/читання SQLite та JSON, пазли як чернетки, клітинки й оформлення, авторизація/спарювання та попередній рушій. Web UI перевіряється у Chromium. Нативні оверлеї збираються для Windows amd64; фізичну роботу з Windows/Android потрібно перевірити на ваших пристроях.
