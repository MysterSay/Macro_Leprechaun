# Шаблон відкритого доповнення

1. Скопіюйте папку в data/plagin/example.
2. У програмі перечитайте доповнення, увімкніть приклад і збережіть.
3. Додайте пазл з категорії «Приклад».

plugin.ps1 — виконання та змінні; manifest.json — оголошення; editor.html — власна форма; settings.html — опис. Компілятор не потрібен. Після збереження plugin.ps1 наступний виклик використовує новий код. Після зміни manifest.json перечитайте доповнення.

Для нового доповнення змініть id у маніфесті та звернення до example__message у коді. Одне доповнення має одну категорію. Документація: docs/ADDON_API_V2.md.
