# Відкрите доповнення: pcstats

Скопіюйте всю цю папку в `data/plagin/pcstats`, перечитайте доповнення, увімкніть і збережіть зміни. Збірка не потрібна.

- `manifest.json` — ID, змінні, пазли й сторінки налаштувань.
- `plugin.ps1` — код, що виконується при запиті. Редагуйте у UTF-8; зміни діють з наступного запуску/опитування.
- HTML-файли — власні форми й опис.

Всі метрики типово вимкнені; їх вмикають у settings.html. Відсутні лічильники повертають `unavailable`.

Повний протокол та приклади: `docs/ADDON_API_V2.md`. Скрипти використовують системний Windows PowerShell; окремі EXE/DLL доповненню не потрібні.
